# Team Recommendation: Northwest Architecture Studio Workstations

**Mini Project 1 · Team 4: The Avengers**

## 1. Comparison of the four builds

Each build follows the work its role does.

| | Administrative Assistant | Project Manager | Architect / CAD Designer | 3D Visualisation Specialist |
|---|---|---|---|---|
| Main work | Email, documents, spreadsheets, online meetings | Reports, dashboards, planning, reviewing drawings, client calls | CAD drawings, 2D drafting, 3D modelling | Rendering, large 3D models, high-resolution textures |
| Graphics | Built into the CPU | Built into the CPU | RTX 3060 12GB | RTX 5070 Ti 16GB |
| RAM | 16GB | 32GB | 32GB | 64GB |
| Storage | 500GB | 1TB | 1TB | 2TB |
| Screens | 1 × 24" | 2 × 24" | 2 × 27" QHD | 1 × 27" 4K |
| Cost per PC | £808.81 | £1,296.59 | £1,844.50 | £3,445.21 |

The Administrative Assistant and Project Manager builds have no graphics card, because their software runs on the graphics built into the CPU. That money went on memory and screens. The Project Manager has reports, dashboards and video calls open at once, so their build has twice the memory of the Administrative Assistant's and a second screen. The CAD Designer needs a graphics card for 2D drafting and 3D modelling, and two QHD screens for detailed drawings. Rendering large 3D models is the heaviest work in the studio, so the 3D Visualisation build has the strongest processor, the most memory, the largest drive and the most powerful graphics card, and it is the only build over £3,000.

## 3. Ethics and professionalism

### 3.1 Responsible purchasing

The team matched each build to what its role needs and left out anything the role would not use, which kept the total £4,317.47 under target.

Every price comes from a known UK retailer, with a link to the shop page as evidence, so anyone can check it.

The Administrative Assistant, Project Manager and CAD builds use 80 PLUS certified power supplies (Bronze or Gold). To be certified, a power supply must be at least 80% energy efficient at 10%, 20%, 50% and 100% of its rated load (CLEAResult, N.D.), so less electricity turns into waste heat.

The Project Manager and CAD builds have spare memory slots, so the studio can upgrade them later rather than replace them. UK businesses must keep waste to a minimum by trying to prevent, reuse, recycle or recover it, in that order (GOV.UK, N.D.), and machines that can be upgraded help with the first two.

### 3.2 Secure handling of client information

The studio handles client information such as building plans and contact details. Under the UK GDPR, it must keep personal data secure through "appropriate technical and organisational measures", which include keeping IT equipment secure and disposing of electronic waste properly (Information Commissioner's Office, N.D.).

When these workstations replace the old PCs, the old drives will still hold business data. The National Cyber Security Centre (NCSC) advises that any storage which has held sensitive business data should be sanitised before the device leaves the organisation, and that pressing "Delete" is not enough (National Cyber Security Centre, 2016). The same applies when the new workstations reach the end of their life.

The brief leaves software licences out of this budget, including the operating system and antivirus, because the firm's central IT team buys them separately, so setting up encryption and security software on each workstation is that team's job.

### 3.3 Data integrity

The team database refuses bad data. Every role, build and item has a unique ID, every item must belong to a build that exists, required fields cannot be blank, and costs must be numbers. Marcus and Nah each tested these rules by entering bad data on purpose, and the database refused every attempt. Their evidence is in [`01_Contributions/Marcus_SQL`](01_Contributions/Marcus_SQL/SQL_Query_Evidence.md) and [`01_Contributions/Nah_SQL`](01_Contributions/Nah_SQL/SQL_Query_Explanations_Nah.md).
