# Individual Reflection: Mini Project 2 (Pennine Pizza Works)

**Marcus Weeks · Role: Design (and test plan design)**

## My role and what I did

My job was the Design stage. I took Charlie's Analysis and turned it into a plan Sorena could build from. That meant a structure chart breaking the program into Main and 12 smaller subroutines, a main flowchart, a data plan for the arrays and variables, a specification for every subroutine, the pseudocode for each one, and the test plan with the expected results worked out by hand.

## How I learned it

Before this project I didn't know anything about flowcharts, pseudocode or subroutines. I learned by working through the problem step by step with Claude, and by using the tutor's slides and the Supercar Gold Standard example. The example showed me what a finished design looks like, so I followed its layout. Together we figured it out one part at a time.

## What was hardest

The hardest part was working out what needed to be done and getting it organised. Once I knew what to do and how it should be done, it was pretty straightforward.

## What I got wrong and fixed

The price array was set up as text instead of a number with decimals. Prices have to be numbers for the totals to work, so I changed it to Real.

My first draft used its own requirement numbers. I switched to Charlie's R1 to R29 so every part of the design traces back to his Analysis. The test plan was also missing columns, so I added them.

Two subroutines, getCustomerDetails and checkBlank, only said "same as Supercar". After checking the tutor's example I wrote their steps out in full. One sentence also said Main declares every array, which stopped being true once the label array went inside getCustomerDetails, so I corrected it.

## What I'll do differently next time

I'll check the tutor's example before I call something finished, because that would have caught the missing steps sooner. I'll make a plan of everything that's needed before I start, since organising was the hardest part. And I'll agree things like numbering with the team earlier, so we're all working from the same list.
