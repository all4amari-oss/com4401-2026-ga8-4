# Individual Reflection: Mini Project 2 (Pennine Pizza Works)

**Nah'Kajsha Reid · Role: Tester (testing Sorena's Flowgorithm program against Marcus's test plan)**

## My role and what I did

I was the tester for Mini Project 2, and I had to run 18 tests. In the first round, 11 of the 18 tests failed. I made Sorena and Marcus aware of what needed fixing. I did a second round of testing after Sorena fixed the problems from the first round. Everything was fixed except the wording of some error messages. Marcus wanted the program to match his design word for word, so he told Sorena what needed to be changed. Once Sorena had made the second set of fixes, I ran the tests for a third time, and everything passed. This was interesting, because one small mistake, even in the wording, can make a test fail.

## How I learned it

Before this project, I was not familiar with Flowgorithm. I originally used a MacBook, but I had to switch to an ASUS (Windows) laptop, because Flowgorithm only runs on Windows. I followed Marcus's test plan and typed in each test's data exactly as it was written. I took screenshots of all the inputs and bills as evidence, and I compared what the program showed with what the plan expected. I was not too sure what I was doing when I ran the first test, so I asked Claude to simplify the steps. I also asked Claude to check that the screenshots I was using as evidence were correct. Other than that, I ran every test myself and decided whether each one passed or failed. Having run the tests three times, I feel confident that I could use Flowgorithm again if I needed to.

## What was hardest

The hardest parts of this project were getting started, and deciding whether to pass or fail a test when the program worked but the wording was different. Keeping track of all the screenshots, and making sure each one matched the correct test, was not easy either. I got past this by making a rule: if the wording was different from the design, I failed the test and wrote a note explaining why. I used the same rule for every test, so my results were consistent.

## What I got wrong and fixed

On the first test, I clicked Run on a blank, untitled program. I fixed this by downloading Sorena's file and opening it in Flowgorithm, then I pressed Run to begin the test. Some of my screenshots did not show the bill, so I retook them to make sure all the information was showing.

## What I'll do differently next time

Next time, I will check the file name before pressing Run. I will also agree with the team before testing whether a difference in wording counts as a fail, so there is no confusion afterwards. I will also scroll all the way down to make sure the entire bill is showing before taking a screenshot.
